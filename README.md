# 📘 MAD 2 Notes — Modern Application Development 2

Exam-focused notes, Previous Year Question (PYQ) solutions, and revision material for **Modern Application Development 2 (MAD 2)** — a course in the **IIT Madras BS Degree in Data Science and Applications**.

The notes cover JavaScript (ES6+), Vue.js 2, Vuex, Flask-based APIs, and web application architecture, and are built directly from analysis of past quiz and end-term papers. Several notes are written in **Hinglish** for easier understanding.

## 📖 Topics Covered

### JavaScript
- `this` keyword, arrow vs normal functions
- Objects, `const`, closures, `var` scoping
- Arrays & higher-order functions: `map()`, `filter()`, `find()`, `forEach()`
- Callback functions, `Map`, `Set`, `WeakMap`, destructuring, generators
- Iterables & iterators
- Event loop, `setTimeout()`, `setInterval()`
- Synchronous vs asynchronous JS, Promises, `async`/`await`
- Fetch API (GET/POST requests, form data, file upload)
- DOM manipulation

### Vue.js 2
- Directives: `v-bind`, `v-on`, `v-model`, `v-if`, `v-show`, `v-for`
- Reactivity system, computed properties vs methods
- Components & props, dynamic class binding, named slots
- Form validation (client-side vs server-side)
- **Vuex**: state, getters, mutations, actions, mapping helpers, modules

### Backend / APIs
- Persistent storage: cookies, `sessionStorage`, `localStorage`, IndexedDB
- Web application architecture
- REST API design (resource/URL design, HTTP methods, JSON responses)
- Authentication & authorization, token-based auth, JWT
- Flask API + authentication
